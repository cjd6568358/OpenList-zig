## 中（应修或产品决策，全部亲验）

- **M1 `sign_all` 默认值反转（安全姿态）**：Zig `config.zig:542` 默认 `false`；Go `internal/bootstrap/data/setting.go:171` 默认 `"true"`。全新部署下 Go 所有下载需签名、Zig 默认公开可下载。用户备份里是 `true`，仅影响新部署。
- **M2 pan115 link 丢 header**：`pan115.zig:697` 返回 `.header = &.{}`；Go `drivers/115/driver.go:77` 挂 `downloadInfo.Header`（`DownloadWithUA` 填 UA+Set-Cookie；115 直链按 UA 授权）⇒ 下游以任意 UA 下载可能 403。
- **M3 189pc 上传串行**：`cloud189pc.zig:2111-2126` put→streamUpload 无线程；Go `drivers/189pc/driver.go:369-454` errgroup 并发（默认 3 线程）。`upload_thread` 配置成死配置，大文件慢数倍。
- **M4 quarkuc 缺变体判据**：`quarkuc.zig:253`（`__pus` 吸收）与 `:471`（转码链）对所有变体生效；Go 仅 `d.config.Name == "Quark"` 才走（`drivers/quark_uc/util.go:55`、`driver.go:66`）。UC 变体行为分叉。
- **M5 wopan 重试过宽**：`wopan.zig:438` 任意 `RSP_CODE!="0000"` 都刷 token 重试；SDK 仅 `"9999"`（`wopan-sdk-request.go:42`）。沃盘 refresh_token 一次性，误刷无谓轮换+写盘。
- **M6 itvsh 上传重试范围**（代理，未亲验）：Zig 仅 `AuthFailed` 重登；Go `drivers/itvsh/upload.go:73-76` 对每块任何错误 retry 3 次+指数退避。弱网上传成功率差异明显。
- **M7 webdav SharePoint 分支未移植**（代理）：`vendor=sharepoint` 的 odrvcookie SSO 流程缺失（Go `drivers/webdav/util.go:15-34`）。
- **M8 local 默认拒绝软链**：`local.zig:195-246` `follow_symlinks` 默认 false ⇒ 含软链路径直接 `InvalidPath`；Go `drivers/local/util.go:30-47` `isSymlinkDir` 默认跟随。路由器/USB 挂载常见场景。
- **M9 fs/get 缺 `thumb`/`hashinfo` 字段**：`api.zig:1296-1333` 只发 name/size/is_dir/modified/created/sign/type/raw_url/readme/header/provider/related；Go `server/handles/fsread.go:35-47` `ObjResp` 含 `Thumb`/`HashInfoStr`。前端详情/预览缩略图与哈希信息取空。另 `writeObj`（`api.zig:3722-3738`）list 项只有 `hash_info:null`，缺 `hashinfo` 字符串键。
- **M10 缺失路由（非已知边界）**：Go `server/router.go` 有而 Zig `isRegisteredAuthedPath`（`api.zig:620-637`）无：`fs/other`、`fs/batch_rename`、`fs/regex_rename`、`fs/recursive_move`、`fs/remove_empty_directory`、`PUT fs/form`、`POST fs/link`、`fs/search`；以及 `/ad/*` `/ap/*` `/ae/*`（`router.go:54-59`，压缩包内下载/代理）、`admin/meta/*`×5（122-127）、`admin/message/*`×2（178-180）、`admin/setting/reset_token`（161）。前端点到落 NoRoute ⇒ **200+HTML**，axios 解析失败 ⇒ 静默无响应。
- **M11 登录错误码 + 无防爆破**：Zig `api.zig:1025-1043` 返 400 `wrong username or password`；Go `server/handles/auth.go:47-64` 返 **401** `InvalidUsernameOrPassword`，且 `LoginCache` 同 IP ≥5 次锁 5 分钟回 **429** `TooManyAttempts`；Zig 无限重试。
- **M12 fs/dirs 形状/语义不符**：Zig `api.zig:1136-1159` 返 `data:{content:[{name,path,driver,label,order}]}`（列挂载点）；Go `server/handles/fsread.go:160-180` 返**裸数组** `[{name,modified}]`（列请求路径的子目录）。形状与语义双重不符。
- **M13 Go admin token 入口收窄**（代理）：Go `server/middlewares/auth.go:19-31` 第一分支接受 settings 表 token（Authorization 头常量比较，**对所有端点有效**）；Zig 仅 `/api/admin/user/del_cache` 收 `zig.token`。持 Go token 的第三方工具/脚本在 Zig 上全 401。
- **M14 logout 不即失效**（代理，有注释文档化）：Go `auth.go:67-73` `InvalidateToken` 后立即失效；Zig `api.zig:1695-1700` 仅返成功，旧 token 到期前仍有效。
- **M15 CORS 默认列表**：Zig `api.zig:758-769` 固定 methods `GET,POST,PUT,DELETE,OPTIONS,PROPFIND`（缺 PATCH/HEAD、无空格分隔）、headers 固定 4 个（缺 `Depth`/`Destination`/`Overwrite` ⇒ 浏览器 WebDAV 预检失败）；Go `server/router.go:256-261` + `internal/conf/config.go:227-231` 默认三项 `["*"]`（gin-contrib 默认方法集含 PATCH/HEAD；`*` 头反射请求头）。
- **M16 `putZig` 与 `save()` 并发竞态**：`config.zig:163+` 直接改 root 对象（重分配 keys/vals），与 `config.zig:249-263` 的序列化交错 ⇒ 可能写出丢键/半新半旧的 config.json。触发：itvsh 后台 cookie 刷新 save 与前台设置保存并发。
- **M17 `reloadAdminCredentials` 非原子+泄漏**：`api.zig:180-183` 三个字段逐个 dupe 替换，请求线程无锁读（穿插时旧 hash 配新 salt）；旧副本永不释放（每次 del_cache 泄漏 3 块）。

## 低（记录在案，多为已文档化取舍或影响有限）

## 已确认对齐（不必再查）

- **密码哈希**：`TwoHashPwd` 双层加盐逐字节一致（`api.zig` static_hash_salt/hashPwd/staticHash vs `internal/model/user.go:24,235-245`）；randomSalt 字符集 = Go `pkg/utils/random/random.go:14`；登录常量时间比较。
- **JWT**：HS256 标准三段、payload {username,pwd_ts,exp,iat,nbf}（`server/common/auth.go:25-40`）。
- **下载签名**：带 padding 的 url-safe base64 + `:expire`、expire=0 永不过期、负值即过期、TrimSuffix 单斜杠（`pkg/sign/hmac.go:25-48` + Down 中间件四种错误）。
- **HTTP 语义**：API 错误信封恒 200+body code（`server/common/common.go:87-104` vs `http.zig:338-344`）；下载端点真状态码+HTML（`common.go:47-77` vs `http.zig:350-361`）；NoRoute 非 GET/POST→405 否则 200 HTML（`static.go:213-227` vs `api.zig:603-612`）。
- **storage CRUD** 8 路由 + `?id=` 解析失败 400 + init 失败带 `data.id` 信封 + 列表含 errored/disabled 行。
- **驱动名 11/11 逐字节**等于 Go `Config.Name`；pan123/quarkuc/itvsh 的 `copy=NotSupport` 与上游一致（有测试钉住）。
- **189 登录 SSO 回跳（toUrl）**双侧都有：Zig `cloud189.zig:636-645`；Go `drivers/189/login.go:122-137`（2026-10-17 刚修）。
- **全 16 驱动扫描**：`ArenaAllocator.init(alloc)`+`toOwned` 模式**仅** cloud189.zig / cloud189pc.zig 两个文件（即 H1/H2），其他驱动无同类；5 个网盘驱动 link header 均无悬垂栈数组（quarkuc/pan123 历史修复仍在位）。
- **wopan 协议主体**：dispatcher URL 拼接、`md5(key+resTime+reqSeq+channel)`、reqSeq 范围、IV、key 选择（api-user=clientSecret / wohome=accessToken[:16]）、PKCS7+标准 base64、DATA 密文判断、8MiB 分片与"最后一片=剩余"语义，对齐 vendor SDK。
- fs/list 字段与 Go `FsListResp` 对齐（除 `hashinfo` 细见 M9）；Zig 配置为 Go 的合理子集（边界见 `docs/STATUS.md` §22）。
